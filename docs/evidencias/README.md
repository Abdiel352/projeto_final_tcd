# Registros de demonstração

Esta pasta pode guardar **registros reais** obtidos durante a montagem e os
testes. Use nomes descritivos e anote as condições do teste junto de cada
arquivo.

Exemplos de registros úteis para a proposta:

- Logs seriais de envio, ACK, timeout, retransmissão e descarte por CRC;
- Foto do texto mostrado no LCD receptor;
- Arquivo original e arquivo reconstruído no PC receptor, com seus hashes;
- Registro da distância entre as placas e das condições de ruído usadas.

Não há resultados de ensaio incluídos aqui. Adicione apenas evidências
observadas, sem dados pessoais ou identificadores desnecessários dos PCs.
